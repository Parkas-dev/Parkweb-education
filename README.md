# Parkweb Education 📚🎓

‎> منصة تعليمية وتنظيمية لمساعدة طلاب البكالوريا في إدارة الوقت والمراجعة اليومية، بعيداً عن القلق من الدراسة وضغوط الحياة 😉

‎🌐 **الموقع:** https://parkweb-education.vercel.app/

---

‎## 🌟 الميزات الحالية
‎- **📅 الجدول اليومي التفاعلي:** إضافة المهام وتعليمها كمنجزة وحذفها، ويُحفظ على جهاز الطالب.
‎- **📚 صفحات المواد:** مواد الشعب العلمية والتقني رياضي (الهندسات الأربع) والمواد الأدبية واللغات، لكل مادة أقسام للمواضيع والتمارين والأفكار.
‎- **📌 توجيه اليوم:** رسالة تحفيزية تظهر لكل الطلبة.

‎## 🗺️ ميزات مخطّطة
‎- ⏱️ مؤقت التركيز (Pomodoro)
‎- 📊 متابعة التقدم
‎- 🤝 قسم الأسئلة والمتابعة
‎- 🔐 حسابات حقيقية بكلمة مرور (تحتاج خلفية Backend)

---

‎## ✏️ كيف تعدّل المحتوى

‎كل الإعدادات في أعلى وسم `<script>` داخل `index.html`:

‎- **توجيه اليوم:** عدّل `SITE_CONFIG.dailyNote`.
‎- **رابط التواصل لقسم الأسئلة:** اضبط `SITE_CONFIG.contactUrl` (تيليغرام أو واتساب أو `mailto:`).
‎- **محتوى المواد:** أضف الروابط داخل `RESOURCES` (يوجد مثال في التعليق).

‎بعد رفع التعديل إلى GitHub يعيد Vercel نشر الموقع تلقائياً.

---
